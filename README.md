# Nexus Hardware

Sitio web institucional para una tienda de componentes de PC de alta gama. Este proyecto ha sido desarrollado simulando un entorno de trabajo profesional real, aplicando metodologías ágiles y un flujo de trabajo colaborativo estricto en Git y GitHub.

## Tecnologías Utilizadas
* **HTML5 Semántico** para una estructura accesible y optimizada.
* **CSS Moderno (Flexbox)** para el diseño modular, limpio y completamente responsive.
* **Git & GitHub** para el control de versiones y gestión del equipo.

## Distribución del Trabajo Colaborativo
Para evidenciar el flujo de trabajo, el desarrollo se dividió en 4 roles independientes gestionados a través de **GitHub Issues**:

1. **Participante 1 (Rama `feature-header`):** Desarrollo del `<header>` y menú de navegación responsive con Flexbox. *(Cierra el Issue #1)*.
2. **Participante 2 (Rama `feature-main`):** Desarrollo de la sección principal `<main>` (Hero Section / Banner de bienvenida). *(Cierra el Issue #2)*.
3. **Participante 3 (Rama `feature-servicios`):** Maquetación de la sección de componentes destacados mediante `<section>` y `<article>`. *(Cierra el Issue #3)*.
4. **Participante 4 (Rama `feature-footer`):** Implementación del formulario de cotizaciones y diseño final del `<footer>`. *(Cierra el Issue #4)*.

## Flujo de Trabajo Aplicado (Workflow)
Cada componente del sitio siguió estrictamente el ciclo de desarrollo profesional:
`GitHub Issues ➔ Branch Local ➔ Commits Descriptivos ➔ Push Remoto ➔ Pull Request ➔ Code Review ➔ Merge a Main`
